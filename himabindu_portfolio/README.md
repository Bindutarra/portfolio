# Tarra Himabindu — Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `himabindu_portfolio` folder.
3. Double-click `index.html`, or use the VS Code Live Server extension.

No build tools or package installation are required.

## Customize
- Update contact details and links in `index.html`.
- Add verified project repository or live-demo links when available.
- Replace the initials-based hero graphic with a profile photo if desired.
- Edit colors, spacing, and typography in `style.css`.

## Deploy with GitHub Pages
1. Create a GitHub repository named `portfolio` (or `<your-username>.github.io`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. Copy the generated public URL into your resume.
